# Мастер-чек-лист тестирования: Myna Quick Note

Данный документ является единым источником тест-кейсов и проверок для GNOME-расширения Myna Quick Note.

## 1. Установка и инициализация
- [ ] Клонирование/копирование файлов в директорию расширений (`~/.local/share/gnome-shell/extensions/myna-quick-note@diserere.github.com`).
- [ ] Наличие обязательных полей в `metadata.json` (`uuid`, `shell-version`, `name`, `description`).
- [ ] Перезапуск GNOME Shell и успешная активация расширения (`gnome-extensions enable ...`).

## 2. Интерфейс (UI) и верхняя панель
- [ ] Отображение иконки расширения на верхней панели GNOME Shell.
- [ ] Клик по иконке открывает выпадающее меню / панель быстрых заметок.
- [ ] Корректное применение стилей (`stylesheet.css`) при светлой и темной темах GNOME.

## 3. Основной функционал заметок (MVP)
- [ ] Ввод текста заметки в поле ввода.
- [ ] Сохранение заметки (кнопка сохранения / автосохранение).
- [ ] Отображение списка созданных заметок.
- [ ] Удаление или редактирование существующей заметки.

## 4. Системные логи и стабильность
- [ ] Отсутствие ошибок (Error / Critical) в `journalctl /usr/bin/gnome-shell` при включении, выключении и использовании расширения.
- [ ] Корректное освобождение ресурсов при выключении расширения (`disable()`).
