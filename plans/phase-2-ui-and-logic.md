# План реализации: Фаза 2 — UI быстрого редактирования и логика MVP

- **Цель:** Реализовать всплывающее диалоговое окно с полем ввода (`St.Entry`), надежным фокусом клавиатуры и копированием отредактированного текста в системный буфер обмена (`St.Clipboard`) по нажатию `Enter`.

## Основные задачи
1. **UI диалогового окна (`extension.js`):**
   - Создать контейнер (`St.BoxLayout`) с полупрозрачным фоном / рамкой.
   - Добавить поле ввода текста (`St.Entry`) с поддержкой фокуса ввода (`stage.set_key_focus`).
   - Добавить индикатор/метку статуса или подсказку для пользователя.
2. **Логика клавиш и буфера обмена:**
   - Обработка нажатия клавиши `Enter` в поле ввода.
   - Получение текста из `St.Entry`.
   - Запись текста в системный буфер обмена через `St.Clipboard.get_default()`.
   - Закрытие/скрытие диалогового окна после копирования.
3. **Стилизация (`stylesheet.css`):**
   - Настроить отступы, цвета фона, радиус скругления и шрифты для диалога и `St.Entry`, гармонирующие с темой GNOME Shell.

## Верификация и тестирование
- Проверка появления диалогового окна.
- Проверка наличия фокуса в поле ввода сразу при открытии.
- Проверка редактирования текста.
- Проверка копирования в буфер обмена по `Enter` и закрытия окна.
