# План разработки расширения GNOME Shell: Myna Quick Note

## 1. Цель и назначение проекта
Создать расширение для GNOME Shell в Ubuntu 26.04, которое:
- Интегрируется с новой встроенной технологией распознавания речи **Myna**.
- Предоставляет удобное всплывающее окно (диалог) для предварительного просмотра и быстрого редактирования распознанного текста.
- Решает проблему совместимости с проблемными или консольными полями ввода.

---

## 2. Стратегия разработки (MVP vs Фаза 2)

### MVP (Минимально жизнеспособный продукт)
1. **Вызов по горячей клавише / триггеру:** Открытие всплывающего диалогового окна поверх остальных окон.
2. **Буфер редактирования:** Отображение распознанного текста в активном поле ввода (`St.Entry`), где гарантирован фокус клавиатуры.
3. **Исправление текста:** Пользователь правит текст вручную.
4. **Копирование в буфер:** По нажатию `Enter` или кнопки текст автоматически копируется в системный буфер обмена (`St.Clipboard`) и окно закрывается.
5. **Вставка:** Пользователь вставляет текст в любое целевое приложение (GUI или терминал) привычным способом (`Ctrl+V`).

### Фаза 2 (Будущее развитие)
- Автоматическая имитация вставки текста в фокусное окно целевого приложения (с учетом специфики Wayland и консольных приложений).

---

## 3. Этапы реализации MVP

### Этап 1: Каркас расширения (Scaffolding)
- Создание `metadata.json`, `extension.js`, `stylesheet.css`.
- Базовая регистрация в GNOME Shell.

### Этап 2: Интерфейс быстрого редактирования (UI)
- Разработка диалогового окна на базе `St.BoxLayout` и `St.Entry`.
- Стилизация под тему GNOME / Ubuntu.

### Этап 3: Логика работы
- Интеграция с горячими клавишами.
- Захват текста, редактирование, копирование в `St.Clipboard` по `Enter`.

### Этап 4: Тестирование
- Проверка работоспособности в GNOME Shell (Ubuntu 26.04).
