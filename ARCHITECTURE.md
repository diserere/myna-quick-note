# Архитектура проекта Myna Quick Note

Данный документ описывает архитектурные решения, стек технологий и принципы работы расширения GNOME Shell `myna-quick-note`.

## 1. Стек технологий
- **Язык:** JavaScript (GJS — GNOME JavaScript).
- **Платформа:** GNOME Shell (целевая ОС: Ubuntu 26.04).
- **Библиотеки UI:** `St` (Shell Toolkit), `Clutter` (сценарий анимации и раскладки).

## 2. Архитектурные принципы и решения

### 2.1. Разделение на MVP и Фазу 2
- **MVP (Текущий этап):**
  - Фокус на надежности и простоте.
  - При срабатывании расширения открывается модальное окно с полем ввода (`St.Entry`).
  - Пользователь редактирует текст и нажимает `Enter`.
  - Текст автоматически копируется в системный буфер обмена (`St.Clipboard`).
  - Пользователь вставляет текст в нужное приложение (включая консольные агенты разработки) вручную через `Ctrl+V`.
  - *Преимущества:* полное отсутствие сложностей с управлением фокусом окон на Wayland и спецификой вставки в эмуляторы терминала.

- **Фаза 2 (Будущее):**
  - Эксперименты с автоматической инъекцией текста в фокусное окно (эмуляция событий клавиатуры / вставки).

### 2.2. Компоненты расширения
- `extension.js`: Точка входа GNOME Shell Extension, инициализация горячих клавиш и жизненного цикла.
- Модальный диалог (`QuickNoteDialog`): Обертка над `St.Bin` / `St.BoxLayout` для отображения текстового поля и кнопок управления.
