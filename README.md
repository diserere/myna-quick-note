# Myna Quick Note

Расширение для GNOME Shell в Ubuntu 26.04, предназначенное для удобного редактирования и управления текстом, распознанным с помощью встроенной технологии голосового ввода **Myna**.

## Описание проблемы
При использовании голосового ввода в различных приложениях (особенно в консольных агентах разработки, специализированных полях ввода или веб-интерфейсах) системное распознавание не всегда корректно определяет целевое поле ввода или не дает возможности комфортно исправить ошибки перед отправкой текста.

## Стратегия разработки

### MVP (Минимально жизнеспособный продукт)
1. **Вызов по горячей клавише / триггеру:** Открытие всплывающего диалогового окна поверх остальных окон.
2. **Буфер редактирования:** Отображение распознанного текста в активном поле ввода (`St.Entry`), где гарантирован фокус клавиатуры.
3. **Исправление текста:** Пользователь правит текст вручную.
4. **Копирование в буфер:** По нажатию `Enter` или кнопки текст автоматически копируется в системный буфер обмена (`St.Clipboard`) и окно закрывается.
5. **Вставка:** Пользователь вставляет текст в любое целевое приложение (GUI или терминал) привычным способом (`Ctrl+V`).

### Фаза 2 (Будущее развитие)
- Автоматическая имитация вставки текста в фокусное окно целевого приложения (с учетом специфики Wayland и консольных приложений).
